Cloudflare Worker

Der Worker läuft auf deinem Cloudflare-Account und verbindet GitHub Pages mit Nextcloud. Dein Passcode wird im Worker als Umgebungsvariable gespeichert – nicht im Browser.

1
Worker erstellen Cloudflare Dashboard → Workers & Pages → Create → Worker. Den Code aus cloudflare-worker.js einfügen und deployen.
2
Umgebungsvariablen setzen Worker → Settings → Variables → Add:
NEXTCLOUD_URL = deine WebDAV-URL
NEXTCLOUD_PASS = dein App-Passcode
NEXTCLOUD_FILE = lerncoaching.json
3
Worker-URL hier eintragen Die URL sieht so aus: https://lerncoaching.DEINNAME.workers.dev
Nur die Basis-URL, ohne Pfad. Zu finden im Cloudflare Dashboard unter Workers.
